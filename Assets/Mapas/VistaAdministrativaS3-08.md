# Vista administrativa S3-08

Se crearon Assets/Scenes/AdminLogin.unity y Assets/Scenes/Admin.unity como previsualizaciones aisladas. Reutilizan FuentePixel/FuenteLectura, FormaRedondeadaUI, RespuestaBotonUI y FocoCampoUI mediante las primitivas del constructor visual aprobado. No se crearon prefabs duplicados. El constructor llama esas primitivas privadas por reflexión: una futura refactorización debe convertirlas en una API compartida explícita.

Archivos nuevos: Assets/Scripts/Mapas/InterfazVisual/VistaAdministrativaDemo.cs, Assets/Editor/InterfazVisual/ConstructorAdministrativoDemo.cs, ambas escenas, este documento y sus meta. Modificado: Assets/Editor/InterfazVisual/NavegacionPreviewEditor.cs para admitir AdminLogin/Admin sin cambiar Build Settings. Inicio conserva su aviso administrativo anterior; abrir AdminLogin directamente para probar.

AdminLogin contiene usuario y contraseña enmascarada, Ingresar DEMO, Volver y mensajes. Ingresar abre la maqueta sin autenticación y limpia los campos. No introducir credenciales reales. Admin muestra tres jugadores ficticios A/B/C, filtro local por nombre, selección, Ver desempeño y PDF. Los datos están serializados como instantáneas independientes del motor; no representan usuarios o IDs reales. El botón PDF comunica explícitamente que no se generó ningún archivo.

Los controladores originales permanecen intactos y no se adjuntaron activos. PantallaAdminLogin autentica mediante Usuarios.IniciarSesionAdministrador; PantallaAdmin exige rol administrador, lista jugadores, partidas finalizadas y últimos 15 eventos, y genera/guarda/abre PDF al seleccionar desempeño. ServicioDesempeno ofrece Resumen, ListarJugadores, PartidasDe y eventos con permisos; Resumen incluye puntos, respuestas, decisiones seguras/inseguras, riesgos, buenas prácticas, cambios de ruta e historial. GeneradorReportes.GenerarPdf y DocumentoPdf ya implementan el reporte. Esta maqueta no reproduce esas consultas ni algoritmos y no llama Sesion, base de datos ni generación de PDF.

Pruebas realizadas: compilación y carga real de ambas escenas en Play Mode, ingreso DEMO, selección B, visualización de detalle, aviso PDF, comprobación automatizada de alturas de texto a 1280×720 y Console. No se completó inspección visual nativa, hover temporal, revisión Full HD ni regresión de las otras pantallas en esta etapa; quedan pendientes. No deben interpretarse estas pruebas parciales como certificación final de S3-08.
